# Hospital-Management-System
CH Sharif and Saeed Hospital — Hospital Management System (HMS) + Standalone Pharmacy Integration.

## Project Scope
- **5 HMS Portals:** Super Admin, Admin, Front Desk / Billing, Admission, Inventory Management.
- **3 Standalone Pharmacy Portals:** Pharmacy Super Admin, Pharmacy Manager, Pharmacy Sales / Dispensing Staff.
- **Core Governance:** Strict operational ownership, individual cashier accountability, dual clearance discharge, independent salary payroll & doctor commission.

## Structure
- `ch-sharif-and-saeed-hospital---hms/`: React 19 + TypeScript + Vite + Tailwind CSS Frontend Workstation.
- `prompts/`: Step-by-step modular implementation prompts (01 to 08) for building the Node.js + Express + PostgreSQL (Prisma) backend.
- `PROJECT_MASTER_SPEC.md`: Master specification derived from 17 client documents (Source of Truth v6.3).
- Master Specification PDFs (01 to 17).
